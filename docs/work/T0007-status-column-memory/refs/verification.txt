The audit also found a cast feeding span arithmetic in Buffer::Copy. FlatPool
now constructs the backing byte array. Its Free cast restores the original
byte-element pointer to recover the header. Fields and Arrow child records are
fully constructed before another allocation can fail, so their spans give the
exact destruction counts on rollback. Child pointer arrays, names, and buffer
byte views use placement array results. The Arrow buffer pointer table is a
member array of the constructed export state. Buffer copies use the memcpy
result for Arrow consumers of implicitly created objects (LWG 4064). The
remaining pool-payload casts pass raw storage to construct_at for single
objects and do not perform arithmetic on the cast result.
  https://cplusplus.github.io/LWG/issue4064
